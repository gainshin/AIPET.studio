# UX Workspace Starter — 你的第二大腦起始包

把這整個資料夾複製一份、改名成你的專案名，就開始了。
不需要終端機：所有檔案都是 Markdown，任何編輯器都能開。

## 起手三步

1. **複製資料夾** → 改名（例：`my-product/`）
2. **打開 `wiki/index.md`**，把專案一句話寫進去
3. **每次做了決定**，在 `wiki/decisions/` 開一頁、在 `wiki/log.md` 記一行
   ——這兩個動作就是「第二大腦」和「普通資料夾」的全部差別

## 資料夾地圖

| 資料夾 | 放什麼 | 規則 |
|---|---|---|
| `wiki/` | 所有設計判斷文件 | agent 只讀這裡；文件是判準，不只是紀錄 |
| `wiki/inbox/` | 未整理的雜記、截圖筆記 | 集散地：定期清空、歸位到正式資料夾 |
| `design-system/` | tokens 真相源 + 元件對照 | 改 DESIGN.md，不改散落的色值 |
| `sources/` | PRD、deck、會議紀錄**原件** | 進來後永不改寫；修正寫新版進 log |
| `product/` | POC html、原型產出 | 畫面是文件的投影——每個產出應能指回 wiki 出處 |
| `exports/` | 對外交付的匯出 | 單向：匯出後的修改不回流 |

工作流與稽核機制見 AIPET.studio 主 repo。
